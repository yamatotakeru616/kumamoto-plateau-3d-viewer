# 熊本駅・花岡山 3Dモデル ビューア

国土交通省 PLATEAU（熊本市 2022年度・仕様4.1）の CityGML から構築した、熊本駅〜花岡山周辺（約2.6km × 2.8km）の 3D 都市モデルのビューアです。

- 表示ページ: `index.html`（Three.js 同梱・単一ファイル、モデルは軽量版）
- 建物 10,622 棟・地形は PLATEAU 実データ。駅周辺の屋根 1,611 棟と樹木は推定生成で、ページ内にも明記しています
- 道路・河川は PLATEAU 交通／土地利用モデル、鉄道は国土交通省「国土数値情報（鉄道）N02」から生成

出典: PLATEAU（国土交通省） https://www.mlit.go.jp/plateau/ ／ 国土数値情報（国土交通省）
